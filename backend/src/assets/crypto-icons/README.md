# Iconos de criptoactivos (paquete local)

Segunda fuente de logos (#449), sin red: se usa cuando un activo no tiene logo
en CoinGecko. La primera es CoinGecko y la última, las iniciales del frontend.

- Origen: `cryptocurrency-icons` 0.18.1 (atomiclabs/cryptocurrency-icons),
  carpeta `128/color`. Solo los PNG cuyo nombre es un símbolo válido.
- Licencia: CC0-1.0 (dominio público), según el `package.json` del paquete.
- Cada fichero se nombra con el símbolo en minúsculas (`btc.png`).
- El backend comprueba la firma PNG y el tamaño antes de guardarlo, igual que
  con los logos descargados.
